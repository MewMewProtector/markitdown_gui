# markitdown_gui

**Версия: v0.0.1**

Десктоп-приложение GUI-обёрткой над `markitdown[all]`.
Следит за выбранной папкой, подсвечивает новые поддерживаемые файлы,
позволяет конвертировать их в `.md` и просматривать результат с подсветкой
синтаксиса Markdown.

## Возможности

- Слежение за выбранной папкой (`QFileSystemWatcher`, debounce 500 мс).
- Drag-n-drop файлов и папок прямо в окно.
- Ручное добавление через диалог (фильтр по поддерживаемым расширениям).
- Конвертация выбранных файлов в пуле потоков (`QThreadPool` + `QRunnable`).
- Предпросмотр с подсветкой Markdown (`QSyntaxHighlighter`).
- Тёмная / светлая темы, фреймлесс-окно с кастомным заголовком.
- Журнал конвертаций в SQLite + экспорт CSV.
- Настройки MarkItDown: LLM (OpenAI-совместимый), Document Intelligence,
  Content Understanding, плагины, аудио/YouTube.

## Требования

- Python **3.10+**
- Windows 10 / 11 (для сборки `.exe`)

```bash
pip install -r requirements.txt
```

```bash
pip install -e .
```

```bash
python -m app
```

```bash

```

## Использование

1. Откройте вкладку **«Настройки»**, выберите **папку сканирования** и
   (опционально) **папку сохранения**. Если папка сохранения пуста — `.md`
   файлы сохраняются рядом с исходниками.
2. Сохраните настройки. Приложение начнёт следить за выбранной папкой.
3. На вкладке **«Файлы»** появятся новые поддерживаемые файлы с галочками.
   Двойной клик по строке — переход к предпросмотру уже сконвертированного
   `.md` (если он есть).
4. Отметьте нужные файлы и нажмите **«Преобразовать выбранные»**.
5. Прогресс и итоги — на вкладке **«Лог»**.

### Описание картинок

Поддерживаются три уровня:

| Уровень | Что покрывает |
|---|---|
| **L1** | `.jpg` / `.jpeg` / `.png` файлы — описание добавляется в конец `.md` блоком `# Description:`. |
| **L2** | Картинки внутри `.pdf` — описание группируется по страницам (`## Page N`). |
| **L3** | Картинки внутри `.docx` / `.pptx` / `.xlsx` — описание добавляется плоским списком под `## Описания изображений — <имя_файла>`. |

Все три уровня управляются **одной** галочкой **«Описывать картинки (LLM)»**
на вкладке «Настройки» и используют те же поля `llm_api_key` /
`llm_base_url` / `llm_model` / `llm_prompt` — подходят любые OpenAI-
совместимые эндпоинты:

- **Ollama** (локально): `http://localhost:11434/v1`, ключ `ollama`,
  модель `llama3.2-vision:11b`.
- **Gemini** (бесплатный тариф): `https://generativelanguage.googleapis.com/v1beta/openai`,
  ключ из Google AI Studio, модель `gemini-2.0-flash`.
- **OpenRouter** (`google/gemini-2.0-flash-exp:free` и т.п.),
  **Groq**, **DeepSeek** — аналогично через их OpenAI-совместимый `base_url`.

Как включить:

1. Вкладка **«Настройки» → MarkItDown / API** — заполните `base URL`,
   `API key`, `Model`. По желанию задайте `Prompt` (по умолчанию
   «Describe this image in detail»).
2. Поставьте галочку **«Описывать картинки (LLM)»** чуть ниже формы API.
   Нажмите **«Сохранить»** (или **Ctrl+S**) — сверху по центру появится
   подтверждение «Настройки сохранены».
3. Перетащите файлы во вкладку **«Файлы»** и нажмите
   **«Преобразовать выбранные»**. Если в пакете есть хотя бы одна картинка
   или документ с inline-картинками, появится компактный диалог с той же
   галочкой — её можно снять или поставить прямо здесь, настройка
   синхронизируется с вкладкой «Настройки».
4. Результат содержит блок(и) с описаниями (если ключ задан и галочка
   включена) или только текст/EXIF (если галочка выключена).

Кэширование: результаты сохраняются в локальной SQLite по ключу
`SHA256(байты картинки) + модель + промпт`. При повторной конвертации той же
папки LLM больше не вызывается для уже описанных картинок (в том числе
извлечённых из PDF/DOCX/PPTX/XLSX).

Временные файлы: при работе с PDF/DOCX/PPTX/XLSX приложение извлекает
inline-картинки в **свежесозданную** временную папку
(`%TEMP%\markitdown_gui_pdf_imgs_<rand>\` или
`%TEMP%\markitdown_gui_office_imgs_<rand>\`) и **гарантированно** удаляет
её в `finally` после конвертации. Никакие файлы вне этой папки не
затрагиваются. Если LLM ответил ошибкой (таймаут, rate-limit, плохие
байты) — для картинки вставляется placeholder
`> [не удалось получить описание изображения]`, остальные файлы пакета
продолжают конвертироваться.

### Поддерживаемые форматы

PDF, DOC/DOCX, PPT/PPTX, XLS/XLSX, HTML/HTM, MD, CSV, JSON, XML, TXT,
JPG/JPEG/PNG/GIF/BMP/WEBP/TIFF, MP3/WAV/M4A, EPUB, ZIP, MSG/EML,
а также ссылки `http(s)://`.

## Сборка `.exe`

Только локально, **не пушим** `dist/` и `build/`:

```bash
pip install pyinstaller
pyinstaller --noconfirm packaging/markitdown_gui.spec
```

Артефакт — `dist/MarkItDownGUI.exe`.

```
│   └── core/                # config (SQLite), watcher, converter, jobs
└── packaging/
    └── markitdown_gui.spec  # PyInstaller
```
